# Cooperative Gig Services

A mobile-based platform that connects customers with local service providers for household and gig services. The application helps users discover services, request assistance, manage service bookings, and make secure payments through a single platform.

## Features

- User registration and authentication
- Customer and service-provider management
- Household and gig service discovery
- Service request and booking management
- Worker profiles and management
- Location-based service handling
- KYC verification
- Secure online payment integration
- Admin dashboard
- Multilingual support
- Service status and request tracking

## Technology Stack

- React Native
- Expo
- TypeScript
- Node.js
- Firebase
- PostgreSQL
- Drizzle ORM
- Razorpay
- Tailwind CSS

## Project Structure

- `app/` – Application screens and navigation
- `components/` – Reusable UI components
- `server/` – Backend functionality
- `payment-backend/` – Payment-related services
- `firebase/` – Firebase services
- `drizzle/` – Database configuration
- `hooks/` – Custom application hooks
- `assets/` – Images and other assets
- `tests/` – Test files
- `docs/` – Project documentation
